# Архитектура проекта

## Общая идея
Проект создается с нуля как отдельное iOS-приложение.
Мы не переносим macOS-приложение целиком, а берем только полезные идеи и безопасно переиспользуем общую логику.

## Слои проекта

### shared
Общий слой с логикой, не зависящей от платформы.
Здесь будут модели данных, парсинг профиля подключения и валидация настроек.

### app
Слой интерфейса приложения.
Здесь будут экраны, кнопки, статус подключения и работа пользователя с профилем.

### ios_native
Нативный iOS-слой.
Здесь будет VPN-часть, связанная с Apple Network Extension и Packet Tunnel Provider.

## Принцип разделения
Интерфейс не должен содержать низкоуровневую VPN-логику.
Платформенная iOS-часть не должна смешиваться с общей логикой профилей и настроек.

## Первая версия
Первая версия приложения сосредоточена только на одном режиме: split VPN.
